## Суть проекта

**«Миллион на салфетке»** — питч-шоу Forbes. Предприниматели из регионов России питчат идеи перед советом Forbes в борьбе за реальные инвестиции от 1 000 000 рублей.

**Формат:**
- **Основной выпуск:** YouTube, 40–60 минут, три предпринимателя в одном эпизоде
- **Нарезки:** Instagram Reels + YouTube Shorts, ~60 секунд, один питч — один исход
- **Логика:** снимаем полный выпуск → нарезаем лучшие моменты → дистрибуция

**Структура выпуска:**

**Вступление (~5 мин):**
- Короткое представление формата и сути шоу
- Представление членов совета Forbes (каждый — 20–30 секунд)
- Представление трёх предпринимателей-участников (каждый — 20–30 секунд)
- Каждый предприниматель получает салфетку и пишет на ней название своего проекта
- У каждого члена совета — своя салфетка на столе

**Три питча по одинаковой схеме (~10–15 мин каждый):**

1. **Питч (5–10 мин):** предприниматель презентует проект. Озвучивает сумму инвестиций, которую хочет получить, и долю, которую готов отдать.
2. **Раунд вопросов и офферов:** каждый член совета по очереди в микрофон задаёт вопросы и называет свою сумму и долю — либо говорит «Я пас».
3. **Торг:** предприниматель и заинтересованные инвесторы договариваются об условиях. Инвестор может выйти в любой момент.
4. **Выбор:** предприниматель выбирает одного инвестора — или уходит ни с чем, если никто не сделал оффер или условия не устроили.
5. **Финальный жест:** предприниматель передаёт свою салфетку с названием проекта выбранному инвестору. Инвестор пишет на ней итоговую сумму и долю. Оба коротко обсуждают следующие шаги.

**Возможные исходы каждого питча:**
- ✅ Сделка — предприниматель и инвестор договорились, салфетка передана
- ❌ Отказ — никто из инвесторов не сделал оффер или все сказали «Я пас»
- ❌ Разрыв — оффер был, но предприниматель не принял условия

**Символика салфетки:** у каждого участника — своя салфетка. Путь салфетки предпринимателя: пустая → имя проекта → передана инвестору → сумма сделки. Это главный визуальный образ шоу.

## Критерии отбора кандидатов

### Обязательные требования

1. **Активно ищут инвестиции** — ключевой критерий. Прибыльные самодостаточные бизнесы не подходят. Нужны те, кому деньги нужны для роста прямо сейчас.
2. **Реальные цифры** — выручка, количество клиентов, рост. Без цифр — не берём.
3. **Верифицированы в авторитетных источниках** — только публикации в:
   - Forbes Russia
   - РБК / RBC
   - Коммерсантъ
   - Тинькофф Бизнес / Biz360
   - Секрет фирмы
   - Региональные: e1.ru, 66.ru, dk.ru, ura.news (для Екатеринбурга), ngs.ru (Новосибирск)
4. **Актуальность:** материалы должны быть актуальны на дату съёмок (проверять, что бизнес не закрыт, не в конфликте, цифры не устарели)
5. **Чистая репутация:** не иноагент, нет уголовных дел, нет крупных публичных скандалов

### Кого НЕ брать

- Бизнес уже прибыльный и не нуждается в инвестициях (пример: Flowwow — слишком большой)
- Компания без реального основателя с именем и лицом
- Нет публичных источников с реальными цифрами
- Слишком маленький бизнес (выручка до 10–15 млн руб., 1–3 сотрудника)
- Бизнес-гигант (Золотое яблоко с 155 млрд оборота — инвестиции не нужны)

### Идеальный кандидат

- Выручка 50–500 млн руб., стадия роста
- Нестандартная идея или интересная история
- Четкий план: зачем инвестиции и на что
- Масштабируемость или экспортный потенциал
- Живой, харизматичный основатель

## Технические детали презентаций

### Структура файлов

```
MILLION-NA-SALFETKE/
├── index.html                  ← Казань (корневая)
├── novosibirsk.html            ← Новосибирск (источник)
├── novosibirsk/
│   ├── index.html              ← Копия novosibirsk.html (для GitHub Pages)
│   ├── og-novosibirsk-2026.jpg
│   └── [novosibirsk-candidate-X.jpg]
├── ekaterinburg.html           ← Екатеринбург (источник)
├── ekaterinburg/
│   ├── index.html              ← Копия ekaterinburg.html (для GitHub Pages)
│   ├── hero-new-ekaterinburg.jpg
│   ├── hero-new-mobile.jpg
│   ├── og-novosibirsk-2026.jpg ← (нужен свой OG для Екб)
│   └── [ekaterinburg-candidate-X.jpg]
```

**Правило:** каждый город — самодостаточная папка. После правки источника всегда синхронизировать:
```bash
cp ekaterinburg.html ekaterinburg/index.html
git add ekaterinburg.html ekaterinburg/index.html && git commit -m "..." && git push
```

### Фото кандидатов

- Формат: JPEG
- Имя файла: ASCII-only, без кириллицы, без пробелов
  - Шаблон: `[город]-candidate-[N].jpg`  (пример: `novosibirsk-candidate-3.jpg`)
- Сжатие перед добавлением:
  ```bash
  sips -Z 900 --setProperty formatOptions 75 "имя-файла.jpg"
  ```
- Конвертация PNG → JPEG:
  ```bash
  sips --setProperty format jpeg "файл.png" --out "файл.jpg"
  ```

### OG-превью (Telegram/социальные сети)

**Важно:** и `og:image`, и `twitter:image` должны быть абсолютными URL. Если один тег сломан — превью не работает.

```html
<meta property="og:image" content="https://lukinmiami-max.github.io/million-na-salfetke/[город]/og-[город]-2026.jpg">
<meta property="og:image:width" content="1200">
<meta property="og:image:height" content="1200">
<meta property="og:url" content="https://lukinmiami-max.github.io/million-na-salfetke/[город]/">
<meta name="twitter:card" content="summary_large_image">
<meta name="twitter:image" content="https://lukinmiami-max.github.io/million-na-salfetke/[город]/og-[город]-2026.jpg">
```

Проверка превью: бот `@WebpageBot` в Telegram.
После смены OG-картинки — сменить имя файла (Telegram кеширует по URL).

## Forbes Design System — стиль презентаций

### Концепция
Тёмный, строгий, дорогой. Золото как единственный акцент. Газетная типографика + современный sans-serif. Никакой яркой пёстрости — только власть и капитал.

### Цветовая палитра

| Токен | Hex | Использование |
|---|---|---|
| `--black` | `#0c0c0c` | Основной фон |
| `--dark` | `#141414` | Секции, фоны карточек |
| `--card-dark` | `#1a1a1a` | Карточки кандидатов |
| `--white` | `#ffffff` | Основной текст |
| `--off-white` | `#f5f2ec` | Светлые секции, тёплый фон |
| `--warm-gray` | `#e8e4dc` | Разделители на светлом |
| `--text-muted` | `#888880` | Вторичный текст, метки |
| `--text-body` | `#3a3a38` | Основной текст на светлом |
| `--gold` | `#c8a84b` | Главный акцент — Forbes-золото |
| `--gold-light` | `#e2c87a` | Hover-состояния золота |
| `--gold-dim` | `rgba(200,168,75,0.15)` | Фоновый тинт gold-акцентов |
| `--border-dark` | `rgba(255,255,255,0.08)` | Границы на тёмном |
| `--border-light` | `rgba(0,0,0,0.1)` | Границы на светлом |

### Типографика

```html
<link href="https://fonts.googleapis.com/css2?family=Bebas+Neue&family=Manrope:wght@300;400;500;600;700;800&display=swap" rel="stylesheet">
```

| Роль | Шрифт | Размер | Вес | Особенности |
|---|---|---|---|---|
| Заголовки-дисплей | Bebas Neue | 80–120px | 400 | letter-spacing: 2–4px |
| H1 / Названия секций | Bebas Neue | 48–64px | 400 | uppercase |
| Метки / Labels | Manrope | 10–11px | 700 | letter-spacing: 4px, uppercase, gold |
| Основной текст | Manrope | 15–16px | 400 | line-height: 1.7 |
| Имена кандидатов | Manrope | 20–22px | 700 | — |
| Карточные детали | Manrope | 13–14px | 400–500 | color: text-muted |

### Ключевые компоненты

**Навигация:**
```css
position: fixed; top: 0;
background: rgba(12,12,12,0.92);
backdrop-filter: blur(12px);
border-bottom: 1px solid rgba(255,255,255,0.08);
```
- Логотип: «FORBES» в Bebas Neue, цвет gold
- Подпись: «МИЛЛИОН НА САЛФЕТКЕ» в Manrope, text-muted
- Справа: название города (gold)

**Hero-секция:**
- `<picture>` тег: разные фото для desktop/mobile
- Полноэкранная фотография города с тёмным оверлеем
- Заголовок: Bebas Neue, огромный, поверх фото
- Подзаголовок: Manrope, label-стиль, gold

**Карточки кандидатов:**
```css
background: #1a1a1a;
border: 1px solid rgba(255,255,255,0.08);
border-top: 3px solid var(--gold);  /* при ховере */
```
- Фото: 280px высота, object-fit: cover
- Номер кандидата: Bebas Neue, 48px, gold
- Имя: Manrope, 700
- Проект: Manrope, text-muted
- Теги инвест-тезисов: pill-стиль, gold border
- Ссылка на источник: подчёркнутая, gold

**Светлые секции** (совет Forbes, формат):
```css
background: #f5f2ec; color: #3a3a38;
```
Используются для контраста с тёмными блоками.

- `reveal` класс: opacity 0 → 1, translateY(24px → 0), 0.7s ease
- Запуск через IntersectionObserver при scroll
- Stagger через `transition-delay` на дочерних элементах

## Рабочий процесс при создании нового города

1. **Копируем** последний готовый город как основу
2. **Заменяем** все вхождения старого города на новый (Python-скрипт или sed)
3. **Обновляем** совет Forbes: #03 и #04 — локальный предприниматель и омбудсмен региона
4. **Находим 10–12 кандидатов** по критериям выше, с верифицированными источниками
5. **Добавляем Hero-фото** города: desktop (1920×1080) и mobile (portrait)
6. **Создаем OG-картинку** для Telegram-превью: 1200×1200, имя `og-[город]-2026.jpg`
7. **Синхронизируем:** `cp [город].html [город]/index.html`
8. **Публикуем:** `git add + commit + push`
9. **Добавляем фото** кандидатов по мере поступления
